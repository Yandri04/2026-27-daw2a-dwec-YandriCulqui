# ¿Qué problemas puede haber a la hora de ejecutarlo?

Dependiendo del navegador esta activado de manera predeterminada bloquear pestañas emergentes lo cual puede interferir y no mostrarnos las ventanas
por lo cual se recomenda descativar esta opción para el correcto funcionamiento de la actividad

## Comunica ventanas A y Comunica ventanas B

Comunica ventanas A (CVA) actua como redireccionador de comunica ventas B (CVB) mediante un windows open ligado a un boton, al momento de realiza esta acción se despliega la venta CVB e inabilita el input de CVA el cual se les pasara los datos, siendo que en CVB realiza la actualización del imput de CVA , mediante su id y el metodo pasadatos() , y para tener que visualizar el resultado habra que volver a ubicarnos en la venta anteriormente abierta CVA, para ver la actualziación del campo de texto

## Comunica ventanas A2 y Comunica ventanas B2

En este caso se la se realiza un cambio de rol en al ventana CVA2 se setean el dato a cambiar en el input de CVB2 y dando clic al boton se despliega CVB2 con el resultado del input
